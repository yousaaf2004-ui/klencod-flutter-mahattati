# تطبيق محطتي — مشروع Flutter

## فتح المشروع في Visual Studio Code
1. فك ضغط الملف `mahattati.zip`.
2. افتح مجلد `mahattati` من VS Code عبر File → Open Folder.
3. تأكد من تثبيت Flutter وDart extensions وإعداد Flutter SDK.
4. افتح Terminal داخل VS Code ونفّذ:

```bash
flutter pub get
flutter doctor
flutter run
```

5. اختر جهاز Android متصل أو محاكي Android من شريط الأجهزة في VS Code.

## ملاحظات مهمة
- قاعدة البيانات SQLite محلية على الجهاز؛ البيانات لا تتزامن بين المستخدم والمحطة والمستودع والمرور عبر أجهزة مختلفة.
- تشغيل ماسح QR يحتاج كاميرا، لذلك جرّب على هاتف Android أو محاكي يدعم الكاميرا.
- حسابات التجربة المضافة تلقائياً عند إنشاء قاعدة البيانات:

| الجهة | رقم الهاتف | كلمة المرور |
|---|---|---|
| مستودع سبها | 0910000001 | 1234 |
| محطة الوسط | 0910000002 | 1234 |
| إدارة المرور | 0910000003 | 1234 |

- المستخدم العادي ينشئ حساباً من شاشة الدخول.
- هذه نسخة أولية للتجربة وليست نظاماً إنتاجياً؛ كلمات المرور مخزنة كنص عادي، كما أن ربط المحطة بالمستخدم وإدارة الصلاحيات يحتاجان تطويراً قبل الاستخدام الفعلي.
- أضيفت استيرادات `sqflite` الناقصة في شاشتي الحجز والمحطة حتى تتعرفا على `Sqflite`.
